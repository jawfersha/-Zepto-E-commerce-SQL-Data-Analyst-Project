# 🛒 Zepto Data Analysis using SQL

## 📌 Overview
This project focuses on analyzing product-level data from an e-commerce grocery platform (Zepto). The goal is to perform data cleaning, exploration, and extract meaningful business insights using SQL.

---

## 📂 Dataset
The dataset contains product-level information such as:
- SKU ID
- Product Name
- Category
- MRP (Maximum Retail Price)
- Discount Percentage
- Discounted Selling Price
- Available Quantity
- Weight (grams)
- Stock Availability

---

## 🛠️ Tools & Technologies
- SQL (MySQL)
- Excel (for dataset handling)

---

## 🔍 Key Steps Performed

### 1. Data Exploration
- Checked total number of records
- Identified null values
- Analyzed distinct product categories
- Compared in-stock vs out-of-stock products
- Identified duplicate product names

### 2. Data Cleaning
- Removed invalid records (price = 0)
- Converted price values from paise to rupees
- Ensured data consistency

### 3. Data Analysis & Insights

- 🔝 Top 10 products with highest discounts
- 📦 High MRP products that are out of stock
- 💰 Estimated revenue by category
- 🛍️ Products with high price but low discount
- 📊 Categories with highest average discounts
- ⚖️ Price per gram analysis (value for money)
- 🏷️ Product classification (Low / Medium / Bulk)
- 📦 Total inventory weight per category

---

## 📈 Sample Business Questions Answered

- Which products provide the best value based on discounts?
- Which high-priced products are currently unavailable?
- Which category generates the highest potential revenue?
- How does pricing vary per gram across products?
